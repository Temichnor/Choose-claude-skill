# Copilot-skills (eksport fra Claude)

Skillene ligger i `.github/skills/<navn>/SKILL.md` – formatet GitHub Copilot leser (Agent Skills-standarden, samme som Claude).

## Bruk
1. Kopier mappen `.github/skills/` inn i roten av repoet ditt.
2. Commit og push. Copilot (agent-modus i VS Code / Copilot coding agent) finner dem automatisk.
3. Alternativt: legg dem i `~/.copilot/skills/` for personlig bruk på tvers av repoer.
